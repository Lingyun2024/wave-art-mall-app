# 學員編號功能部署指南

## 功能說明

為特定代理人的訂單新增學員編號欄位，格式為「姓氏拼音_編號」（例如：Wei_001、Shye_001）。

## 部署步驟

### 1. 執行 SQL 腳本更新資料庫

```bash
# 在 Supabase SQL Editor 中執行
G:\草稿\待辦事項\APP_!\backend\add_student_number.sql
```

這個腳本會：
- 在 `orders` 表新增 `student_number` 欄位（VARCHAR(20)）
- 根據 `agent_name` 自動填入對應的學員編號
- 建立索引以加速查詢

### 2. 確認資料庫更新

執行以下 SQL 確認學員編號已正確寫入：

```sql
SELECT 
    agent_name, 
    student_number, 
    COUNT(*) as order_count
FROM orders
WHERE student_number IS NOT NULL
GROUP BY agent_name, student_number
ORDER BY agent_name;
```

預期結果應該顯示 8 位代理人及其對應的學員編號。

### 4. 測試驗證

#### 4.1 測試名冊頁面

1. 開啟 `admin-roster.html`
2. 確認表格最右側有「學員編號」欄位
3. 確認有學員編號的代理人訂單顯示正確編號（例如：Wei_001）
4. 確認沒有學員編號的代理人該欄位為空白

#### 4.2 測試總表頁面

1. 開啟 `admin-summary.html`
2. 在「二、代理登記人彙總」表格中
3. 確認表頭有「學員編號」欄位
4. 確認每位代理人的學員編號正確顯示
5. 如果同一代理人有多個訂單，學員編號應該顯示一次
6. 沒有學員編號的代理人顯示「-」

#### 4.3 測試呈總部版本

1. 開啟 `admin-roster-headquarter.html` 和 `admin-summary-headquarter.html`
2. 確認學員編號欄位存在且正確顯示
3. 測試列印 / 另存 PDF 功能
4. 確認 PDF 輸出包含學員編號欄位

### 5. 列印測試

## 新增或修改學員編號

如果需要新增或修改學員編號，請執行：

```sql
-- 新增學員編號
UPDATE orders
SET student_number = '新編號'
WHERE agent_name = '代理人姓名';

-- 例如：新增陳幸容為 Chen_001
UPDATE orders
SET student_number = 'Chen_001'
WHERE agent_name = '陳幸容';
```

## 注意事項

1. **學員編號不會自動更新**：如果訂單的 `agent_name` 改變，需要手動更新 `student_number`
2. **編號格式**：建議保持「姓氏拼音_編號」格式，便於識別
3. **資料完整性**：建議定期檢查學員編號與代理人是否一致
4. **備份**：執行 SQL 腳本前請先備份 `orders` 表
