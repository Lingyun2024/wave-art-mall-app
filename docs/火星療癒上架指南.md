## 六、重要提醒

### 資料庫密碼保護

- `scripts/.env` 與 `.env.local` 已被 `.vercelignore` 排除
- **絕對不要**把 `SUPABASE_SECRET_KEY` 提交到 Git
- **絕對不要**把 `_run_schema.js` 中的密碼分享給其他人

### 照片隱私

- 照片儲存在 Supabase Storage 私有桶
- 只有管理員與本人能檢視
- 管理後台使用「臨時簽章網址」，有效期 1 小時
- 不會產生永久公開連結

### 個資保護

- 登記資料受 Row Level Security 保護
- 一般使用者只能看到自己的登記
- 管理員能看到所有登記
- 無管理員權限者開啟管理後台會被導向首頁
