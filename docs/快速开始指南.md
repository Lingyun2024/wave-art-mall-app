# 🚀 WAVE ART MALL - 快速开始指南

## 第一步：启动本地服务器

在项目文件夹打开命令提示符（PowerShell），输入：

```bash
python -m http.server 8000
```

看到这个提示就表示成功了：
```
Serving HTTP on :: port 8000 (http://[::]:8000/) ...
```

## 第二步：打开浏览器

在浏览器地址栏输入：
```
http://localhost:8000
```

你会看到 WAVE ART MALL 的首页！

## 第三步：测试七七地赦功能

1. **点击首页的"特殊节日"图标** (红色庆典图标)
2. **观看5个宣传视频** - 可以左右切换
3. **选择一个方案** - 例如点击"個人者乎"
4. **选择身份** - 再次确认身份
5. **填写资料**：
   - 代表人姓名：张三
   - 虚岁：30
   - 电话：0912345678
   - 地址：台北市信义区
   - 代理人：（可留空）
6. **点击"确认结账"**
7. 系统会提示你登录（如果还没登录）
8. 登录后自动加入购物车

## 📱 测试其他功能

### 注册新用户
1. 点击右下角"个人"图标
2. 选择"注册"
3. 输入邮箱和密码
4. 查收验证邮件（重要！）
5. 点击邮件中的验证链接

### 浏览商品
- 首页就有推荐商品
- 点击任何商品查看详情
- 点击"加入购物车"

### 查看购物车
- 点击顶部购物车图标
- 可以修改数量或删除商品
- 点击"前往结账"

### 完成订单
1. 填写收件信息
2. 选择付款方式
3. 确认订单
4. 完成！

## ⚠️ 重要提示

### 上线前必须做的事：

**在数据库创建"七七地赦"商品**
1. 登录 Supabase 控制台
2. 进入 `products` 表
3. 新增一笔记录：
   ```
   name: 七七地赦 - 個人者乎（或其他方案）
   price: 770（或对应价格）
   description: 本2026年七七地赦特赦方案
   image_urls: ["图片URL"]
   category: 特殊节日
   ```
4. 记下新创建的商品 `id`
5. 打开这两个文件，把 `999` 改成真实的商品ID：
   - `pages/holiday.html` (第330行)
   - `pages/holiday-form.html` (第330行)

查找方式：按 `Ctrl+F` 搜索 `HOLIDAY_PRODUCT_ID = 999`

## 🔍 如何检查是否有错误

**打开浏览器开发者工具**：
- Chrome/Edge: 按 `F12`
- 点击 "Console"（控制台）标签
- 如果有红色错误信息，记下来

常见错误：
- `404 Not Found` → 文件路径错误
- `Network Error` → 网络连接或数据库问题
- `Unauthorized` → 登录过期，重新登录

## 📞 需要帮助？

如果遇到问题：
1. 检查控制台错误信息
2. 确认本地服务器正在运行
3. 确认网络连接正常
4. 尝试清除浏览器缓存（Ctrl+Shift+Delete）
