## 二、角色選配（按當前階段，非全建）

當前階段＝**24 頁重寫**（Phase 3–4），依業務需要選配：

| 角色 | 本站是否需要 | 理由 |
|---|---|---|
| 信息收集專員（查證） | ✅ **需要** | 內容查證已證明是高槓桿（A1 火星色票、A2 GALACTIC 都是它挖出來的） |
| 流程質檢專員（門檻） | ✅ **需要** | 五門檻就是它；24 頁並發改動必須有 |
| 數據復盤專員（指標） | 🟡 半需 | 本次補 `npm run metrics` 後才成立 |
| 文案專員 | 🔴 暫不需要 | 本站文案是既有內容，不是新寫；且四項文案決策等族族拍板 |

**結論**：本站選配＝信息收集 + 流程質檢（+ 輕量數據復盤），符合「一職一能、按需配置」。
