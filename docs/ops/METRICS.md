## 三、回放機制

> 原教程「永久保存」≠ 回放。本站回放靠三層：

| 層 | 載體 | 回答的問題 |
|---|---|---|
| **決策脈絡** | `docs/decisions/ADR-000X` | 「當初為什麼選這個？」 |
| **狀態快照** | `docs/board.md` + `docs/baseline-2026-09-13.md` | 「那時什麼是綠的？」 |
| **產物版本** | git commit + `backups/` | 「改壞前是長什麼樣？」 |

**回放三場景**：
1. 「改了 token 為什麼壞？」→ `git log -p out/rewrite/base/tokens.cjs`
2. 「這頁當初為什麼這樣寫？」→ 查 `docs/content-audit.md` 對應條目
3. 「上線版和本地差在哪？」→ diff `_online_snapshot/` vs `pages/`
