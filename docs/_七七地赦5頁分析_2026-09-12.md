**網址**：127.0.0.1:8765/pages/ `holiday-entry, holiday-select, holiday-form, holiday, my-roster`
**時間**：2026-09-12 00:2x

## 二、問題清單

### 🔴 P0 — 21MB 字型檔，4 個頁面各載一次

`assets/fonts/TEST_latest.ttf` = **21,099,672 bytes（21MB）**

| 載入它的頁面 |
|---|
| pages/my-roster.html:11 |
| pages/holiday-form.html:111 |
| pages/admin-roster.html:11 |
| pages/admin-roster-headquarter.html:11 |

已確認**線上真的部署了**：`https://wave-art-mall.vercel.app/assets/fonts/TEST_latest.ttf` → HTTP 200, Content-Length 21099672。

→ 用手機開 my-roster 或 holiday-form，光字型就要下載 21MB。

**而且還有一個完全沒人用的副本：**
`assets/fonts/MicrosoftJhengHeiRegular0617_TEST_latest.ttf` 也是 21MB，**全站掃描沒有任何檔案引用它** —— 純佔空間（本地 + 線上各 21MB 白丟）。

實測 `my-roster.html` 的 PUA/造字區字元數 = **0**，`RosterCustomGlyph` 只有 font-face 宣告，代表這 21MB 字型很可能只為了少數幾個罕見字。用 fonttools subset 可以壓到幾十 KB。

### 🔴 P0 — holiday.html 標題是疊字壞文案

```
<title>本2026(丙午)年之數數數數數量量量量量特以特赦領證如下 | WAVE ART MALL</title>
```

「**數數數數數量量量量量**」出現在兩處：
- `holiday.html:6` — `<title>`（LINE 分享、瀏覽器分頁看得到）
- `holiday.html:226` — 頁面正文（宋体 26pt）

這是複製貼上／OCR 造成的疊字。

### 🟠 P1 — holiday-select.html 做好但沒接上

- 全站掃描：**沒有任何頁面連到它**
- `holiday-entry.html` 的 5 張方案卡（191/195/199/203/207 行）**全部直接連 `holiday-form.html?plan=...&identity=...`**，完全繞過 select
- 它的功能（「請選擇您的特赦身分」→ 選完導向 form）跟 entry 的方案卡**重複**

→ 當初應該是做了 select 版，後來改成 entry 直接帶 `?identity=` 參數，select 就忘了接／忘了刪。

## 三、做得好的地方 ✅

- **5 頁零空連結**（`href="#"` 數量全為 0）—— 比宗教 8 頁、火星 5 頁都乾淨
- 5 頁都有返回元素（arrow_back / 返回文字）
- `my-roster.html` 功能完整：需登入（`requireLogin` 類邏輯）、未登入顯示「請先登入 / 前往登入」、無資料有空狀態、有分頁（`PAGE_SIZE = 10`）、有**列印 / 另存 PDF**
- `holiday.html` 明確標註「本次地赦日已結束／本頁保留為活動紀錄與入口導覽，已不再受理本次登記」—— 這是**有意保留的歷史頁**，不是壞掉
- `holiday.html` 的影片輪播有做 lazy load（點擊才建 video 標籤），註解寫明把 65MB 降到幾十 KB
