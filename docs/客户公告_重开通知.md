# 客户重开通知文案（可贴 Line / 微信 / Email）

> 用途：站点恢复后，主动通知之前下过单的客户。
> 背景：历史订单 / 收藏 / 地址数据已因系统异常清空，需请客户重新注册或重设密码后重新下单。
> 使用方式：把【】里的内容换成你自己的信息，挑一个渠道发出去。

---

## 版本一：Line / 微信 群发或私讯（口语、简短）

```
【店铺名】親愛的貴賓您好：

我們網站近期進行系統升級，您的「歷史訂單、收藏與收貨地址」資料在升級過程中遺失，
造成困擾我們深感抱歉 🙏

網站现已恢复营业，您可以：
1. 若原本就有帳號 → 登入頁點「忘記密碼？」重設後即可使用
2. 若無法登入 → 直接用原信箱重新註冊即可

因歷史訂單資料已無法復原，若有未完成的訂單或特殊需求，
請直接回覆本訊息或來信【你的信箱】，我們會優先為您處理。

再次感謝您的包容與支持，期待再次為您服務！
```

---

## 版本二：Email 正式公告（较完整）

```
主旨：【WAVE ART MALL】系統升級完成通知暨致歉

親愛的客戶 您好：

感謝您一直以來對 WAVE ART MALL 的支持。

我們近期完成了網站系統升級。在此誠摯說明：在升級過程中，
部分客戶的「歷史訂單、收藏清單與收貨地址」資料不幸遺失，
我們對此疏失深感抱歉，也已在技術層面完成檢討與防範。

為不影響您後續選購，請依以下方式繼續使用：

• 原有帳號：請至登入頁點擊「忘記密碼？」，依信件連結重設密碼後登入。
• 無法登入／新客戶：請直接用您的信箱重新註冊。

若您曾有未完成之訂單或特殊需求，請來信【你的信箱】並附上
當時聯絡方式，我們將盡速為您協助處理。

再次感謝您的理解與一路相伴，我們會持續把服務做得更好。

WAVE ART MALL 團隊 敬上
```

---

## 发出前的小提醒
- 如果你手上有「银行转账」客户的入账记录，可优先主动联系他们，避免他们困惑。
- 文案里【你的信箱】请换成你实际会看的邮箱。
- 建议先小范围（几个熟客）发出确认无误，再全量发送。
